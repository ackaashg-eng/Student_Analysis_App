# Student Exam Score Analysis

## Overview

Student Exam Score Analysis is a Python application that analyzes exam marks for 10 students using mathematical concepts commonly used in Machine Learning.

The project demonstrates how Python can be used to collect data, calculate statistical measurements, analyze probabilities, and visualize student performance using Matplotlib.

## Features

- **Data Collection:** Accepts exam marks for 10 students and stores them in a Python list.
- **Statistical Analysis:** Calculates mean, median, maximum score, minimum score, variance, pass percentage, and fail percentage.
- **Probability Analysis:** Calculates the probability of selecting a student who passed, scored above 80, or failed.
- **Data Visualization:** Generates four graphs using Matplotlib:
  - Bar Chart — Student vs Marks
  - Line Chart — Marks Trend
  - Histogram — Score Distribution
  - Scatter Plot — Student Number vs Marks
- **Function-Based Design:** Organizes the application into reusable functions for better readability and maintainability.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/student-exam-score-analysis.git
   ```

2. Navigate to the project directory:

   ```bash
   cd student-exam-score-analysis
   ```

3. Install the required library:

   ```bash
   pip install matplotlib
   ```

## How to Run

Run the Python application using:

```bash
python student_analysis.py
```

Enter the marks for each of the 10 students when prompted. The application will display the statistical and probability results and generate four graphs.
